# VRC Tier 0 Project Check

This is a browser-based first-pass project check for Vulnerability Reduction Credits.

## Use it

Open `index.html` in a browser. No installation is required.

Answers are saved in the browser on the same computer. Use the save button to download a copy of the answers, and the load button to open saved answers later.

## Share it

Send the full folder or the zip archive. The app needs these files together:

- `index.html`
- `styles.css`
- `app.js`

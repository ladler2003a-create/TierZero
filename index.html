A first-pass check for adaptation projects

This tool helps project owners see whether an adaptation project has enough basic information to be considered for a deeper Vulnerability Reduction Credit (VRC™) review.

What you get

  • A simple read on whether the project is ready for deeper review.
  • A list of must-fix issues and missing answers.
  • A short summary you can save and share.

Why use it

Adaptation projects often have strong practical value but uneven documentation. This check shows where the case is already clear and where more support is needed.

Time needed

A quick first pass can take 15 to 30 minutes if you know the project. A stronger pass may take longer if you need to collect sources or estimates.

What helps

Useful inputs include a project description, map or service area, climate-risk source, rough loss estimates, monitoring plan, and claim owner.

How to answer

Use practical answers. Rough numbers are acceptable if you explain the source or assumption. Leave a note when the answer is uncertain.

What this is not

This is not VRC approval, legal advice, or a final credit estimate. It is a structured way to decide what is ready and what needs work.

Privacy

Answers are saved in this browser on this computer. Use the save button if you want to keep or share a copy of the answers.

Suggested workflow

  1. Enter a project name.
  2. Answer the questions with the best information available.
  3. Use the Overview page to see must-fix issues and missing answers.
  4. Save a summary or answers file for follow-up.
